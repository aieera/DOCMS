# SeDoc full-codebase review — 2026-10-12

Branch `neu-ui` at `e9e74eec` (working tree, read-only). Scope: all 14 Go services, `pkg/`, `cmd/`, the two Python workers, the Node collaboration server, the Kotlin signer, `web/`, `extension/`, `addins/`, `mobile/`, `deploy/`, compose files, Dockerfiles and CI.

## 1. Method and limits

- **Fleet round.** Nine reviewer seats (auth; tenant isolation; document+storage; policy/search/audit/notification/workflow/task; gateway/mcp/connector/billing/signature; web; Python workers; deploy/CI/secrets; pkg/cmd) each produced findings with file:line evidence. The tenant-isolation seat was lost to a rate limit and re-run as a mechanical RLS and raw-pool inventory.
- **Verification round.** Every CRITICAL/HIGH and most MEDIUM findings were handed to adversarial verifiers run as Claude Octopus personas (`octo:personas:code-reviewer`, `security-auditor`, `frontend-developer`, `deployment-engineer`), instructed to refute. Verdicts below are theirs; "reported only" marks items no verifier reached.
- **Objective checks** run by the coordinator: Go build/vet/race tests for all 20 workspace modules, govulncheck, web tsc/eslint/vitest, npm audit, integration-module vet.
- **Octopus multi-provider dispatch could not run.** `orchestrate.sh spawn` and `code-review` route the reviewer role to the Codex CLI, which is not installed here; forcing `--provider claude` does not change the route. All seats therefore ran as Claude agents following the Octopus persona and round structure. No external-model cross-check happened.
- **Nothing was executed against a live stack.** No exploit was attempted; `helm` is not installed so chart rendering is reasoned from templates; Python dependency CVEs are from pins, not an audit run.
- **Not reviewed** (seats ran out of budget): storage WORM/reencrypt/rewrap internals; document NATS consumers in depth; WOPI/OnlyOffice, sync, IRM, watermark, zt-share, templates, records certification; QES/TSP flows; pades parser robustness; connector email/intake capture/eventstream internals; most admin pages in web; Word add-in and Google add-on logic; mobile screens; deploy/monitoring, ansible role tasks; migration lock profiles.
