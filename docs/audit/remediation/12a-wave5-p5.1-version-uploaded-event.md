# Remediation 12a — Wave 5 Prompt 5.1: publish `dms.version.uploaded.v1`

**Date:** 2026-04-17
**Wave:** 5 (event pipeline)
**Prompt:** 5.1
**Source:** `DMS Architecture/final.md` § 4.3.
**Status:** ✅ landed end-to-end in code; awaiting live run + Prompt 5.2 stream bootstrap.

## Headline

The critical blocker identified in § 2.2 of the completion spec is
resolved: every successful `CreateVersion` call now emits
`dms.version.uploaded.v1` through the outbox in the same SQL
transaction. The intelligence pipeline (OCR → classify → embed →
preview) now has a publisher.

## Spec deviation (ADR 0021)

final.md § 4.3 directed storage's `CompleteUpload` to emit the event.
Recon showed `version_id` is not defined inside that transaction —
versions are created later by document service's `CreateVersion`.
Emitting from storage would either violate the payload contract
(empty `version_id`) or require inverting the upload flow. The
emission point moved to document service; full rationale in
[docs/adr/0021-version-uploaded-event-emission-point.md](../../adr/0021-version-uploaded-event-emission-point.md).

## What's NOT in this PR

- **Stream declaration** — creating `DOC_EVENTS` with the proper subject
  binding is Prompt 5.2. Until that lands, the event will publish but
  may not be retained/bound correctly in environments that haven't
  auto-created the stream.
- **DLQ subject** — `dms.version.uploaded.v1.DLQ` is part of Prompt 5.2's
  topology.
- **Consumer dedupe** — each consumer (OCR, classify, embed) owns its
  own `processed_events` table. Those are Prompts 5.3–5.5.
- **Integration test** — requires a full docker-compose (postgres, nats,
  minio, redis) and is currently blocked on the CI integration-job
  still being Wave 13.1.
- **RestoreVersion event parity** — when Wave 2a's `RestoreVersion`
  emits `dms.version.restored.v1`, it does NOT also emit
  `dms.version.uploaded.v1`. Intentional: restore reuses an existing
  blob, so OCR/embed already ran on it. Logged in
  [docs/backlog/out-of-scope.md](../../backlog/out-of-scope.md).
