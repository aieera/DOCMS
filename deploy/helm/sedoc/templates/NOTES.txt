  admin once, against the owner DSN, with a strong password of your own:
    kubectl port-forward svc/{{ include "sedoc.dbHost" . }} 5432:5432 &
    cd scripts/seed && DATABASE_URL='postgres://<owner>:<pw>@localhost:5432/{{ .Values.global.database.name }}?sslmode=require' \
      SEED_ADMIN_EMAIL=<you@example.com> SEED_ADMIN_PASSWORD='<strong>' \
      SEED_TENANT_SLUG=<slug> SEED_TENANT_NAME='<name>' SEED_REGION={{ .Values.global.s3.region }} go run .

Upgrading an existing deployment (read before `helm upgrade`):
  1. Migrations run as a pre-upgrade hook, BEFORE new binaries roll out
     (document 000104-000113, auth 000003/000004, audit 000006,
     notification 000004, connector 000002, billing 000012 ...). Never run
     a subset: golang-migrate does not go back for lower numbers once a
     higher one is recorded.
  2. Services now connect as dms_app (NOBYPASSRLS). The hook creates it and
     sets the default privileges; a database whose tables were created
     before those defaults existed needs a one-time GRANT matching
     scripts/init-db.sql (SELECT/INSERT/UPDATE/DELETE on the tables,
     USAGE/SELECT on sequences) — keep the organizations / audit_events
     REVOKEs from document 000001.
  3. Audit chains written before the canonical-hash fix need a one-time
     re-baseline, or GDPR erasure answers 409 audit_chain_unverifiable:
     docs/runbooks/audit-chain-rebaseline.md (owner DSN + audit signing key,
     dry run first, no rollback — back up first).
  4. JetStream durables for audit / search / notification / policy are
     recreated with a deliver group on first start of the new build. Roll
     ONE replica of each first (two upgrading the same legacy durable can
     strand one). To roll BACK, delete those durables before starting the
     old build (it cannot bind to grouped durables); see
     docs/runbooks/05-nats-topology.md.
  5. New required configuration: the KEK Secret (no longer optional), the
     NATS and Redis passwords, the platform secrets (IRM key, zt pepper —
     setting/rotating it invalidates live zero-trust links — OnlyOffice
     JWT), the signer keystore, collaboration.allowedOrigins if browsers
     use another origin than https://{{ .Values.global.domain }}.
